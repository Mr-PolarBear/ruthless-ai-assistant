# 快捷提示系统功能说明

## 1. 概述

快捷提示（Quick Prompts）系统是专为提高日常聊天输入效率而设计的高阶文本模板与光标控制系统。用户既可以通过聊天输入区左下角的闪电图标快速悬浮调出常用提示词与标点模板，也可以在设置模态框中自由增删、编辑、置顶、拖拽排序以及自定义光标注入行为。

---

## 2. 核心特性

1. **高阶光标与文本注入引擎**：
   - **智能光标定位**：支持「内容开头」、「内容中间（单数智能 -1 居中）」、「内容结尾」及「自定义第 N 个字后」四种光标落点计算。
   - **四种插入模式**：支持「当前光标位置」、「当前行开头」、「当前行结尾」和「下一行（自动补全换行符）」。
2. **开箱即用内置预设**：
   - `双引号“”`：插入成对引号，光标自动居中在 `“”` 内部。
   - `双星号**`：插入 `****` Markdown 加粗标记，光标自动居中在星号内部。
   - `括号()`：插入 `()`，光标自动居中在括号内部。
   - `移到行首`：文本为空，光标瞬间定位到当前光标所在行的行首。
   - `移到行尾`：文本为空，光标瞬间定位到当前光标所在行的行尾。
   - `换行`：在光标处或下一行换行。
   - 30+ 常用编程、写作、翻译等提示语预设。
3. **便捷交互与排序机制**：
   - **悬浮展开**：聊天区闪电按钮支持 `mouseenter` 悬浮即出，配 200ms 智能延时防抖，保证鼠标平滑滑入菜单不闪烁。
   - **弹窗加高**：最大高度升级至 `min(480px, calc(100vh - 120px))`，默认可完整展示前 10 条项目。
   - **一键置顶**：设置列表中每项均提供「移动到第一条」按钮，点击立即排到最顶部。
   - **新增默认排第一**：新添加的提示语默认直接插入到数组第 0 位。
   - **防脱节拖拽排序**：拖拽完成后基于当前 DOM 的真实 `dataset.id` 重建数据映射，彻底杜绝多次拖拽或搜索状态下的数据错位。
4. **可靠持久化**：
   - 独立专属 Key（`quick_prompts`）存储，并在全局 `saveToLocalStorage` 中做双重保障，刷新页面永久保存。

## 3. 系统架构与模块划分

系统遵循单一职责与模块化设计原则，拆分为独立的子模块目录：

```
js/quick-prompts/
├── quick-prompt-storage.js   # 专职负责：本地存储持久化、内置预设与老数据规范化兼容
├── quick-prompt-executor.js  # 专职负责：光标落点计算、插入模式判定与文本注入
└── quick-prompt-ui.js        # 专职负责：设置列表渲染、表单动态联动与聊天区浮动菜单生成
js/quick-prompts.js           # 门面出口（Facade），统一导出各子模块功能保持兼容
js/settings/quick-prompt-settings.js # 设置面板事件绑定与拖拽事件监听
```

### 3.1 各模块职责

| 模块 | 核心函数/常量 | 说明 |
|---|---|---|
| `quick-prompt-storage.js` | `DEFAULT_PROMPTS`<br>`loadQuickPromptsFromStorage()`<br>`saveQuickPromptsToStorage()` | 负责管理预设提示词、读取 localStorage 并自动补齐缺失的高阶配置字段默认值 |
| `quick-prompt-executor.js` | `calculateCursorOffset(text, cursorPosition, customCursorOffset)`<br>`executeQuickPrompt(prompt, textarea)` | 核心算法引擎：计算相对光标偏移量并注入目标 `textarea` |
| `quick-prompt-ui.js` | `renderQuickPromptsList(searchTerm)`<br>`populateQuickPromptForm(prompt)`<br>`resetQuickPromptForm()`<br>`renderQuickPromptMenu()` | DOM 渲染与表单动态联动（例如选择自定义时展开数字输入框） |
| `quick-prompts.js` | `initializeQuickPrompts()`<br>`saveQuickPrompts()` | 对外统一门面，供 `main.js` 初始化和全局调用 |

## 4. 数据结构规范

每个快捷提示对象的数据结构如下：

```javascript
{
    id: 'prompt_1700000000000', // 唯一标识符 (String)
    title: '双引号“”',            // 提示标题 (String)
    text: '“”',                 // 插入文本内容，可为空 (String)
    insertMode: 'cursor',       // 插入位置: 'cursor' | 'line_start' | 'line_end' | 'new_line'
    cursorPosition: 'middle',   // 插入后光标: 'start' | 'middle' | 'end' | 'custom'
    customCursorOffset: 1       // 自定义光标偏移 (Number，当 cursorPosition === 'custom' 时有效)
}
```

### 字段枚举与默认值

| 字段 | 可选值 | 说明 | 默认值 |
|---|---|---|---|
| `insertMode` | `cursor` | 当前光标位置插入（覆盖当前选区） | `cursor` |
| | `line_start` | 当前行开头插入 | |
| | `line_end` | 当前行结尾插入 | |
| | `new_line` | 下一行插入（自动前置换行符） | |
| `cursorPosition` | `start` | 光标停留在插入文本的最前面（偏移 0） | `end` |
| | `middle` | 智能居中（双数 `len/2`，单数 `(len-1)/2`） | |
| | `end` | 光标停留在插入文本的最末尾 | |
| | `custom` | 光标停留在第 `customCursorOffset` 个字符后 | |
| `customCursorOffset` | `0 ~ text.length` | 自定义偏移字数 | `0` |

## 5. 核心算法说明

### 5.1 居中计算算法
```javascript
export function calculateCursorOffset(text = '', cursorPosition = 'end', customCursorOffset = 0) {
    const len = text.length;
    if (len === 0) return 0;

    switch (cursorPosition) {
        case 'start':
            return 0;
        case 'middle':
            // 偶数直接除以 2；奇数先减 1 再除以 2（例如长度 2 居中为 1，长度 3 居中为 1）
            return len % 2 === 0 ? len / 2 : (len - 1) / 2;
        case 'custom': {
            const num = parseInt(customCursorOffset, 10);
            if (isNaN(num)) return len;
            return Math.min(Math.max(0, num), len);
        }
        case 'end':
        default:
            return len;
    }
}
```

### 5.2 插入位置算法
```javascript
if (insertMode === 'line_start') {
    const prevNewline = fullVal.lastIndexOf('\n', selStart - 1);
```

## 6. UI 与交互设计

### 6.1 悬浮与点击机制
- 鼠标移入闪电图标时，清除延时并立即展示菜单。
- 鼠标离开闪电图标时，启动 200ms 计时器。
- 鼠标在 200ms 内进入菜单内部，计时器清除，保持菜单展示。
- 鼠标离开菜单后 200ms 自动关闭，或点击外部区域立即关闭。

### 6.2 表单动态响应
- 当「插入后光标」选择 `自定义` 时，下方输入框 `自定义光标偏移` 平滑展开；选择其他选项时自动隐藏。

## 7. 常见问题排查（FAQ）

1. **为什么拖拽排序后刷新页面顺序依然正确？**
   - 拖拽事件完成后，通过直接读取 DOM 中当前所有项的 `data-id` 列表构建 `newPrompts` 并写入 localStorage，杜绝了基于动态索引 `splice` 导致的错位。
2. **文本为空的快捷项有什么用？**
   - 文本为空配合 `insertMode: 'line_start'` 或 `line_end`，可以充当「快速移到行首/行尾」的光标控制快捷键。
