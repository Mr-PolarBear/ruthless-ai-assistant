## 1. 修复代码块按钮点击交互问题

### 问题描述
在 AI 回复流式输出过程中，用户点击已生成的代码块（如点击“复制”、“下载”）失效或不跟手。
**原因分析**：
1.  **DOM 频繁销毁**：`innerHTML` 的全量更新导致已存在的代码块 DOM 节点被反复销毁重建，切断了事件监听器的连接（特别是 `mousedown` 和 `mouseup` 跨越了 DOM 重建）。
2.  **ID 不稳定**：原代码块 ID 生成包含时间戳，导致同一位置的代码块在每次渲染时 ID 不同，无法被 Diff 算法复用。

### 解决方案
1.  **ID 确定性改造** (`js/code-block-enhancer.js`)：
    *   移除 ID 生成中的 `Date.now()`，改为纯计数器，确保同一位置的代码块 ID 始终一致。
    *   引入 `buttonStates` Map，持久化保存按钮状态（如“处理中”、“已复制”），使其能在 DOM 重绘后恢复。
    *   优化 `setupEventDelegation`，防止对同一 ShadowRoot 重复绑定事件。
    *   将下载/预览操作改为同步执行，移除不必要的 `setTimeout`。

2.  **实现增量 DOM 更新** (`js/renderer.js`)：
    *   废弃全量 `innerHTML` 替换。
    *   实现 `updateDomPreservingCodeBlocks` 函数，执行原地 DOM Diff。
    *   **核心策略**：对于 ID 匹配的代码块，**保留其容器节点（Old Element）不动**，仅更新内部的 `<code>` 文本内容。这确保了按钮栏（Header）的 DOM 节点永不被销毁，彻底解决了点击中断问题。

### 验证结果
*   [x] 复制按钮在流式输出中可正常点击，状态正确显示。
*   [x] 下载按钮点击即响应，无延迟。
*   [x] 代码块高亮正常。
