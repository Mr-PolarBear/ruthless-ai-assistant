# 通知提示系统功能说明

## 概述

通知提示系统用于在页面右上角显示非阻塞式的提示信息，支持多种类型的通知，具有醒目的视觉效果和统一的调用接口。

## 样式效果

所有通知都在页面右上角显示，从右侧滑入动画，自动消失。

| 类型 | 样式 | 用途 |
|------|------|------|
| `info` | 蓝色渐变背景 + 白色图标文字 | 一般信息提示 |
| `success` | 绿色渐变背景 + 白色图标文字 | 成功操作提示 |
| `warning` | 橙色渐变背景 + 白色图标文字 | 警告提示 |
| `error` | 红色渐变背景 + 白色图标文字 | 错误提示 |

## 调用接口

### 基础函数

```javascript
import { showNotification } from './ui-updater.js';

// 参数：message(消息内容), type(类型), duration(显示时长，毫秒)
showNotification('操作成功', 'success', 3000);
```

### 便捷对象（推荐）

```javascript
import { notify } from './ui-updater.js';

// 快捷方法
notify.info('这是一条信息');
notify.success('操作成功');
notify.warning('请注意');
notify.error('操作失败', 4000);  // 可自定义显示时长

// 特殊用途
notify.copy();                    // 复制成功提示，默认消息"已复制到剪贴板"
notify.copy('内容已复制');        // 自定义消息
notify.download();                // 下载成功提示
notify.download('文件已下载');    // 自定义消息
```

## 使用场景

| 场景 | 调用方式 | 文件位置 |
|------|---------|---------|
| 复制消息内容成功 | `notify.copy()` | `message-manager.js` |
| 批量删除时提示等待 | `notify.error('请等待...')` | `batch-delete.js` |
| AI输出中切换分支 | `notify.warning('AI正在输出中...')` | `chat-events.js` |
| MCP工具对话进行中 | `notify.warning('当前会话正在进行...')` | `chat-events.js` |
| 新建会话被阻止 | `notify.warning('当前会话正在进行...')` | `main.js` |
| MCP工具复制成功 | `notify.success('工具已复制')` | `mcp-management.js` |
| MCP设置保存成功 | `notify.success('设置已保存')` | `mcp-settings.js` |

## 技术实现

### 文件结构

```
js/ui-updater.js
├── showNotification(message, type, duration)  // 基础函数
└── notify                                      // 便捷对象
    ├── info(msg, duration)
    ├── success(msg, duration)
    ├── warning(msg, duration)
    ├── error(msg, duration)
    ├── copy(msg = '已复制到剪贴板')
    └── download(msg = '下载成功')
```

### 动画流程

1. 创建通知DOM元素，设置初始状态（透明、右侧外）
2. 添加到 `document.body`
3. 10ms后添加 `.show` 类，触发CSS过渡动画
4. 指定时长后移除 `.show` 类
5. 300ms后从DOM中移除元素

## 设计原则

1. **非阻塞**：通知不会阻止用户操作或页面渲染
2. **醒目**：使用渐变背景色和白色文字，对比度高
3. **统一**：所有通知使用相同的样式和调用接口
4. **便捷**：提供 `notify` 对象简化调用
5. **自动消失**：默认3秒后自动消失，可自定义时长
