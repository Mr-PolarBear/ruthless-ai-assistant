# 功能说明-流式请求开关与调试优化

## 概述

本次更新实现了两个主要功能：
1. **调试模式的控制台输出优化** - 改进了虚拟请求记录格式，避免URL编码显示问题
2. **流式请求开关功能** - 允许用户选择使用流式或非流式响应模式

## 1. 调试模式优化

### 问题描述
之前调试模式在控制台输出URL编码的内容，如：`+%22%5Cn%E5%9C%A8+JavaScript+%E4%B8%AD%EF%BC%8C%60setTimeout%60+%E6%`，难以阅读。

### 解决方案
1. **控制台输出格式化**：
   - 将完整内容改为长度显示和前200字符预览
   - 优化日志结构，更清晰地展示响应信息

2. **虚拟请求改进**：
   - 从GET请求改为POST请求
   - 将数据放在请求体中而不是URL参数中
   - 添加自定义请求头用于标识调试信息

### 代码位置
- `js/api.js` - `createDebugResponseLog()` 函数

## 2. 流式请求开关功能

### 功能描述
允许用户在参数设置中开启/关闭流式输出模式：
- **流式模式（默认）**：实时显示AI响应内容，边生成边显示
- **非流式模式**：等待完整响应后一次性显示

### 实现细节

#### UI界面
- **位置**：设置 → 参数设置标签页
- **控件**：切换开关，位于Max Tokens设置下方
- **说明**：包含功能解释的辅助文本

#### 后端逻辑
1. **请求准备**（`api.js - prepareRequest()`）：
   - 根据 `state.appSettings.streamMode` 设置请求的 `stream` 参数

2. **响应处理**（`main.js`）：
   - 流式模式：调用 `handleStream()`
   - 非流式模式：调用 `handleNonStreamResponse()`

#### 数据持久化
- 设置保存在 `localStorage` 中的 `appSettings.streamMode`
- 导入导出配置时自动包含此设置
- 页面刷新后保持用户选择

### 代码文件修改

#### 新增文件
无

#### 修改文件
1. **modals.html**：
   - 在参数设置页面添加流式输出开关UI

2. **js/state.js**：
   - `appSettings` 中添加 `streamMode: true` 默认设置

3. **js/dom.js**：
   - 添加 `streamModeToggle` DOM元素引用

4. **js/ui-events.js**：
   - 添加流式模式开关的事件处理逻辑

5. **js/api.js**：
   - 修改 `prepareRequest()` 中的 `stream` 参数设置
   - 新增 `handleNonStreamResponse()` 函数处理非流式响应
   - 优化 `createDebugResponseLog()` 函数

6. **js/main.js**：
   - 导入 `handleNonStreamResponse` 函数
   - 根据 `streamMode` 设置选择调用不同的响应处理函数

## 3. 使用说明

### 流式请求开关
1. 打开设置面板（右上角齿轮图标）
2. 切换到"参数设置"标签页
3. 找到"流式输出"开关
4. 根据需要开启或关闭
5. 设置会自动保存

### 调试模式优化
1. 在设置 → 显示设置中开启"调试模式"
2. 发送消息给AI
3. 等待响应完成后：
   - 打开F12 → Network面板
   - 查找POST请求到 `/debug/api-response`
   - 在Request Payload中查看完整响应数据
   - 在控制台查看格式化的调试信息

## 4. 技术特点

### 兼容性
- 向后兼容，现有配置不受影响
- 默认保持流式模式，保持原有用户体验

### 性能考虑
- 非流式模式减少了DOM更新频率
- 适合处理大量输出或网络不稳定的情况

### 调试友好
- 调试模式提供详细的响应信息
- 控制台输出结构清晰，易于分析

## 5. 注意事项

1. **API兼容性**：
   - 部分API可能不支持流式响应
   - 建议先测试API是否支持 `stream: false` 参数

2. **用户体验**：
   - 非流式模式下用户需要等待更长时间才能看到响应
   - 建议在网络条件好的情况下使用流式模式

3. **调试模式**：
   - 仅在开发和调试时开启
   - 会产生额外的网络请求和控制台输出

## 6. 后续优化建议

1. **加载指示器**：为非流式模式添加更明显的加载提示
2. **自动检测**：根据网络条件自动建议使用合适的模式
3. **批量设置**：允许为不同API端点设置不同的流式模式偏好
